# EarllnClear — 안드로이드 파일 정리 앱

휴대폰 내부 저장소의 파일을 쉽고 안전하게 정리하는 개인용 Android 앱입니다. (Kotlin + Jetpack Compose)

## 기능
| 기능 | 설명 |
|---|---|
| 🔁 중복 파일 | 크기 → 앞부분 해시 → 전체 SHA-256 순서로 비교해 **내용이 완전히 같은** 파일만 찾습니다. 원본으로 보이는 파일(카메라 폴더 > 이름에 (1)이 없는 파일 > 오래된 파일) 1개를 남기고, 그룹 전체를 선택할 수 없게 막아 둡니다. |
| 🐘 대용량 파일 | 50MB / 100MB / 500MB / 1GB 이상 파일을 크기순으로 보여줍니다. |
| 🕰️ 오래된 파일 | 6개월 / 1년 / 2년 / 3년 이상 수정되지 않은 파일을 보여줍니다. |
| 🧹 빈 폴더 · 임시파일 | 빈 폴더(표준 폴더 DCIM·Download 등은 제외)와 `.tmp`, 미완료 다운로드(`.crdownload`, `.part`), 썸네일 캐시를 청소합니다. |
| 🗂️ 자동 분류 | 선택한 폴더 바로 아래의 파일을 **종류별 / 날짜(연-월)별 / 종류+날짜별** 하위 폴더로 옮깁니다. 미리보기 후 실행하고, **마지막 분류는 되돌릴 수 있습니다.** |
| 🗑️ 휴지통 | 삭제한 파일은 `/.EarllnClearTrash`로 옮겨지며 **30일 안에 복원**할 수 있습니다. 30일이 지나면 자동으로 영구 삭제됩니다(앱 실행 시 + 하루 1회 백그라운드). |

## 안전장치
- 모든 삭제는 확인 창을 거쳐 휴지통으로 옮겨집니다(빈 폴더만 바로 삭제).
- `Android/data`, `Android/obb`, `Android/media` 폴더는 검사하거나 건드리지 않습니다.
- 파일 목록이나 내용은 휴대폰 밖으로 전송되지 않습니다(인터넷 권한 없음).

## 설치 방법
1. GitHub 저장소의 **Actions** 탭 → 최신 **Build APK** 실행 → 하단 **Artifacts**에서 `EarllnClear-apk`를 내려받습니다.
2. zip을 풀어 나온 `app-debug.apk`를 휴대폰에 옮겨 설치합니다. ("출처를 알 수 없는 앱" 설치를 허용해야 합니다.)
3. 처음 실행하면 **모든 파일 접근 허용**을 켜 주세요.

> 참고: 디버그 서명은 빌드할 때마다 바뀔 수 있습니다. 그래서 새 버전이 기존 앱 위에 설치되지 않으면 기존 앱을 지우고 다시 설치해야 합니다.
> 휴지통 파일과 목록은 저장소의 `/.EarllnClearTrash`에 있어서, 앱을 지웠다 다시 설치해도 그대로 남습니다.

## 직접 빌드
Android Studio로 열거나 다음 명령을 실행합니다.
```
./gradlew assembleDebug
```
요구사항: JDK 17, Android SDK 35 / 최소 지원: Android 8.0 (API 26)
